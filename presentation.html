05 · Read

Path params và query params

QUERY PARAM

/menu?q=phở

Thay đổi cách hiển thị danh sách. Link kết quả tìm kiếm có thể lưu và chia sẻ.

PATH PARAM

/menu/2

Xác định một bản ghi cụ thể. Controller đọc ID, gọi findUnique và trả 404 nếu không tồn tại.

Browser → GET /menu/2
route → controller → prisma.dish.findUnique({ where: { id: 2 } })
→ EJS render dish-detail.ejs → HTML trả về browser
06 · Database

Model là nguồn mô tả dữ liệu

prisma/schema.prisma
model Dish {
  id          Int @id @default(autoincrement())
  name        String
  description String
  price       Int
  category    String
  available   Boolean @default(true)
}

Ba model độc lập

Dish quản lý món ăn và giá VNĐ nguyên.

Chef quản lý tên và chuyên môn.

Ingredient quản lý tên và đơn vị tính.

Giá dùng Int thay vì Float để tránh sai số số thực.

09 · HTTP methods

Form HTML vẫn biểu diễn được PATCH và DELETE

Form cập nhật
<form method="POST"
  action="/admin/dishes/2?_method=PATCH">
Form xóa
<form method="POST"
  action="/admin/dishes/2?_method=DELETE">

app.use(methodOverride('_method')) nằm trước router. Server chuyển method logic để khớp với router.patch và router.delete. Không cần AJAX.

12 · Reliability

Lỗi rõ ràng, seed có chủ ý

404 / 500

Tách đúng loại lỗi

404 dành cho URL hoặc bản ghi không tồn tại. 500 dùng view lỗi máy chủ riêng và không leak chi tiết database.

SEED

Không reset nhầm

Seed destructive chỉ chạy khi có ALLOW_DESTRUCTIVE_SEED=true, tránh xóa dữ liệu mà không có xác nhận.

$env:ALLOW_DESTRUCTIVE_SEED="true"; npm run prisma:seed

14 · Kịch bản demo

Trình bày bằng một luồng liền mạch
